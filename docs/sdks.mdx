Because Krixai acts as a universal reverse proxy, it works natively with almost any LLM framework or SDK by simply changing the `base_url` or `http_options`.

### Native SDKs

Krixai supports the native SDKs for OpenAI, Google GenAI, and Anthropic. You do not need to use OpenAI compatibility wrappers.

<CodeGroup>

```python Google GenAI
from google import genai
from google.genai import types

client = genai.Client(
    api_key="AIza...",
    http_options=types.HttpOptions(
        base_url="https://api.krixaisecurity.com",
        headers={"x-krixai-api-key": "kx-live-..."}
    )
)
```

```python Anthropic
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-ant-...",
    base_url="https://api.krixaisecurity.com",
    default_headers={"x-krixai-api-key": "kx-live-..."}
)
```

```python OpenAI
import openai

client = openai.OpenAI(
    api_key="sk-...",
    base_url="https://api.krixaisecurity.com/v1",
    default_headers={"X-Krixai-API-Key": "kx-live-..."}
)
```
</CodeGroup>

### LangChain Integration

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o",
    api_key="sk-...",
    base_url="https://api.krixaisecurity.com/v1",
    default_headers={"X-Krixai-API-Key": "kx-live-..."}
)

# All LangChain chains now route through Krixai automatically
response = llm.invoke("Summarize this legal document...")
```

### LlamaIndex Integration

```python
from llama_index.llms.openai import OpenAI

llm = OpenAI(
    model="gpt-4o",
    api_key="sk-...",
    api_base="https://api.krixaisecurity.com/v1",
    default_headers={"X-Krixai-API-Key": "kx-live-..."}
)
```

### FastAPI Middleware

If you prefer to run Krixai as middleware on your own server rather than proxying outbound requests:

```python
from krixai import KrixaiMiddleware
from fastapi import FastAPI

app = FastAPI()
app.add_middleware(KrixaiMiddleware, api_key="kx-live-...")

# All requests to your AI endpoints are now automatically scanned
```
